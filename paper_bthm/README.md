# BTHM — sources

`bthm_jalc_v2.tex` is the paper. `_appendix_evidence.tex` is the appendix it `\input`s.
`probe_cost_dist/costdist.pdf` is Figure 1. `bthm_jalc_v2.pdf` is the compiled result.

Build:

```
pdflatex bthm_jalc_v2.tex
pdflatex bthm_jalc_v2.tex
```

Both passes are needed: the first writes the references, the second resolves them. The build needs
`graphicx` and the standard `amsmath`/`amsthm`/`booktabs` set, nothing else. No shell escape, no
external data at compile time.

The paper is 27 pages. Every number in it is regenerated by a script in the code deposit; the mapping
from a number to the script that produced it is `claims.json`, and the deposit's `MANIFEST.md` lists
the pairs. `check_paper.py` in the code deposit re-checks that every headline number appears in the
text with the value the deposit records, and that no retired class name, action name or refuted
conjecture survives.
